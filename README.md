# venera-configs
Use AI to modify expired comic sources or add new features.
Currently, we are ensuring that all sources have the following features: the manga detail page can be copied, and after copying the link, it can be analyzed and jumped to in the software's search bar.
Includes secondary development of the source.
The source code of Venera-App has fixed some issues, while others have only added the functionality of copying links and link parsing redirection.
The comic sources from this origin support the functions of copying links and link parsing redirection.
